# CV 编辑技能

这是一个用于按职位描述（JD）定制专业简历的 Codex 技能包，强调真实、可读与有证据的表达。

CV 编辑技能会将 JD 与候选人已核实的经历转化为简洁、便于招聘者快速阅读的 CV：它先匹配岗位需求与证据，再以 STAR 思路写出不冗长的成果 bullet，将最相关经历置前，最后检查两页限制、专业自然的语言、重复表达和排版质量。若没有既有 CV，技能会先进行定向访谈，确保初稿基于真实成就而非猜测。

它可以帮助你：

- 根据 JD 匹配经历排序和措辞，同时不虚构资格或成果；
- 用精简的 STAR 方法改写经历；
- 将每条经历写成“**短语总结：**行动、范围与结果”；
- 按相关性排序职位和 bullet；
- 使用清晰、单栏、专业的简历版式；
- 在交付前检查是否控制在两页内、语气是否专业自然、JD 用词是否贴合、以及是否存在重复表达。

## 安装

1. 下载本仓库中的最新版技能压缩包，或复制本文件夹 `cv-editing`。
2. 解压安装包。
3. 将 `cv-editing` 文件夹复制到 Codex 的技能目录：

   ```text
   $CODEX_HOME/skills
   ```

   若没有配置 `CODEX_HOME`，请使用：

   ```text
   ~/.codex/skills
   ```

4. 如有需要，重启或重新加载 Codex。
5. 可用以下方式调用：

   ```text
   使用 $cv-editing 根据以下 JD 修改我的 CV。
   ```

## 使用说明

使用流程分为三步：

1. 提供 JD 与既有 CV；若没有 CV 或信息不足，回答一组围绕相关职位、成果故事、技能、已核实指标和限制条件的简短访谈问题。
2. 查看生成的 CV：它会按 JD 定制、完成排版，并进行页数、专业语言、重复表达和版式检查。
3. 针对内容、措辞、排序或排版提出建议；技能会在不改变事实的前提下定向调整，并重新进行受影响的检查。

技能会保留真实的日期、职位、雇主、指标和职责范围；若关键信息缺失，会询问或保留占位符，不会编造经历。

完整排版规则见 [references/layout.md](references/layout.md)，两页限制、专业语气、JD 对齐与去重复检查见 [references/quality-check.md](references/quality-check.md)。
