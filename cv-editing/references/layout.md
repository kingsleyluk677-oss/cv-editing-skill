# Compact Professional CV Layout

Apply this layout when the user asks for the supplied template style. Use it as a visual system, not as content to copy.

## Page and hierarchy

- Use an A4 or US Letter page according to the application market; keep margins compact but readable (roughly 1.3–1.8 cm).
- Use a single-column document with a stable left text edge. Keep the first page visually dense enough to show substantive experience without crowding.
- Place the candidate name centered at the top in uppercase or small caps, bold, and a restrained medium blue. Put location and professional contact details on one or two centered lines below.
- Use a clean sans-serif typeface. Set body text around 9.5–10.5 pt; use larger, bold text for the name; set section headings about 11–12 pt.
- Use near-black body text and a single blue accent. Use a pale blue, full-width band behind each section heading; set the heading in bold uppercase blue.

## Section sequence

Use only sections that add evidence. A common sequence is:

```text
Education
Professional Summary & Core Competencies
Professional Experience
Additional Experience
Digital, Media & Administrative Skills / Selected Portfolio
```

Use titles that reflect the target role. Keep any summary factual and compact; do not repeat experience bullets.

## Role block

Set each role as:

```text
Job title (bold, left)                                         Mon YYYY–Mon YYYY (bold, right)
Employer, location (italic, left)
• Summary phrase: action, scope, and result.
• Summary phrase: action, scope, and result.
```

Place dates on the same baseline as the job title. Use a modest vertical gap between role blocks and smaller gaps between bullets. Avoid tables for body content; they can break parsing in application systems.

## Typography and bullets

- Use sentence fragments or full sentences consistently; end all bullets consistently with or without a period.
- Bold only the 2–5 word summary phrase before the colon; keep the explanatory text regular weight.
- Keep emphasis purposeful. Do not bold whole bullet sentences, multiple keyword strings, or decorative labels.
- Indent bullets modestly and use a standard round bullet for reliable document conversion.

## Optional elements

- Put a small portfolio link or QR code only in a final “Selected Portfolio” section and label it with what the reader will find.
- Center page numbers in the footer for documents longer than one page.
- Omit photos, logos, infographics, ratings bars, and decorative sidebars unless a specific creative-industry brief requires them.
